# 会话切换（非并行执行）

底部“会话”按钮打开列表，标注当前会话，支持选择旧会话及新建会话。
会话以默认名称或短 ID 加首条用户消息摘要区分；摘要在后台直接读取 SQLite，
不为展示列表初始化所有 ContextManager，不改变数据库格式。

选择旧会话后恢复原历史并重新绑定工具，当前选择持久化供重启恢复。
选择当前会话不做重置。切换前确认未发送的文字和附件会清空；暂不保存各会话草稿。

已启动的工具完成后仍写入其原会话，但切换后不自动续接。
每次切换递增代次，响应及工具批次捕获启动代次，A→B→A 也不会使旧链路恢复执行。
这不取消已经发出的外部操作，也不提供多会话后台并行能力。

验收：默认旧历史可见；新建后可返回旧会话继续；重启恢复最后选择；
有流式响应、慢工具或延迟重试时 A→B→A 不串流、不自动续接；
同会话选择不清空输入；取消确认不改变会话；图片/视频输入切换后不残留。
